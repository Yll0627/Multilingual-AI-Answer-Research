# 🧠 LingoSpectrum Backend Demo

This is the backend demo for the LingoSpectrum project.

## ✅ Features

- Auto-detects input language using DeepL
- Translates user input into multiple languages (EN, FR, DE, ZH, RU)
- Uses GPT-4 to:
  - Analyze translation quality (semantic, tone, emotion)
  - Generate answers in each target language
- Translates all AI answers back to English for comparison

## 🛠️ Tech Stack

- Python 3.8+
- OpenAI API
- DeepL API
- dotenv, deepl, openai
